# John Daniel Paroligan: Profile Website

Personal portfolio for a virtual assistant, video editor, social media manager and scripter.

Everything is in one file, `index.html`. The photo, styles and scripts are embedded, so there is nothing to install or build.

## Put it online with GitHub Pages
1. Create a new repository on GitHub and upload `index.html` and `README.md`.
2. Go to Settings, then Pages.
3. Under Build and deployment, set Source to "Deploy from a branch".
4. Choose the `main` branch and the `/ (root)` folder, then Save.
5. After a minute your site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

Tip: name the repository `YOUR-USERNAME.github.io` to get the shorter address `https://YOUR-USERNAME.github.io/`.
